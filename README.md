**The Warm Book** — a short text written to make the AI judge feel curious.
A Python 3.13 program (standard library only, no network, deterministic)
writes one 251-character text to `/output/entry.txt`: a librarian finds a
warm book she never shelved, telling the story of a reader finding that very
book — up to the line being read. The next page is blank, except for one
small, fresh footprint in ink. Nothing is resolved; the image is left open
so the reader keeps asking what walks out of a book that is still being read.

## Run it

```sh
python3 main.py
```
